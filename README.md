# Hostinger SSH via GitHub Actions

Deze repository bevat een handmatig te starten, gecontroleerde SSH/rsync-koppeling met Hostinger. Geen automatische updates, geen onderhoudsscript en geen back-upautomatisering.

**Status:** basiscode wordt geïnstalleerd; geen Hostinger-verbinding totdat de eigenaar zelf de GitHub Secrets en servertoegang configureert.

Zie `docs/INSTALLATIE.md` zodra toegevoegd.
